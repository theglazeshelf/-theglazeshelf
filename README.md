# The Glaze Shelf — Deploy v0.5

Fixes and improvements:
- Open Shelf now navigates to a real Studio Shelf screen.
- Empty studios show a clear empty state instead of looking unresponsive.
- Studio Shelf has dedicated Add Glaze / Add Clay actions.
- Adding a studio material returns to the open Studio Shelf and confirms success.
- Studio view highlights Shelf navigation.
- Stale signup confirmation banner is cleared after authentication.

Deploy this ZIP to the existing `theglazeshelf` Vercel project using:
Production Deployment > file > choose ZIP > Deploy to Production.

Existing Vercel environment variables remain in place.
